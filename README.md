
# Administração de Servidores Linux

## Sobre o projeto
Repositório dedicado à documentação de laboratórios práticos de administração de servidores Linux, redes e serviços corporativos.

## Objetivos
- Administrar servidores Linux utilizando o terminal e SSH.
- Configurar e testar serviços de rede.
- Aplicar boas práticas de segurança e disponibilidade.
- Documentar procedimentos de instalação, manutenção e troubleshooting.

## Tecnologias previstas
- Linux (Ubuntu e Debian)
- SSH
- DNS
- Samba
- Squid Proxy
- Firewall
- Shell Script

## Laboratórios
Os laboratórios serão documentados progressivamente, com procedimentos, capturas de tela e resultados dos testes.
